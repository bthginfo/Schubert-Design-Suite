## Implementation safeguards

- Time state, sequence and outbox writes share one IndexedDB transaction. Visible success follows transaction completion.
- Timer duration derives from recorded timestamps. Long real durations are retained.
- Sync is triggered by entering the time page, window focus, reconnection or a manual action. Requests are skipped when there are no pending commands. No periodic database polling is installed.
- The service worker caches versioned static resources and the explicit offline employee page. API responses, portal content and arbitrary private page responses are excluded.
- Financial and external actions wait for the authoritative server response. Generic workflow confirmations bind the displayed record and version. Import approvals name only the explicitly selected row IDs.
- Dialogs have labelled controls, keyboard focus containment and focus restoration. Main application CSS provides reduced-motion support and mobile controls of at least 48 CSS pixels.
